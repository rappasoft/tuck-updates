# Tuck Updates

Public automatic update feed and signed app downloads for Tuck: Menu Bar Organizer. Tuck’s source code is maintained separately in a private repository. Only compiled app archives and update metadata are published here.

Tuck requires an Apple silicon Mac running macOS 27. A purchased license is required to activate the licensed app: **$4.99 once, up to two Macs, no expiry or subscription**. Public downloads do not include a license.

- [Product and purchase information](https://rappasoft.com/apps/tuck)
- [Compatibility and setup](https://rappasoft.com/apps/tuck#requirements)
- [Support](https://rappasoft.com/apps/tuck#support)

Automatic updates use [appcast.xml](appcast.xml) in this repository and signed ZIP assets in the [updates release](https://github.com/rappasoft/tuck-updates/releases/tag/updates). No GitHub account is required.
